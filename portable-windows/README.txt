TOOL FINDY FOR WINDOWS - LOCAL-FIRST
====================================

START
  Double-click start-findry.cmd.
  Your normal browser opens Tool Findy at http://127.0.0.1:4173.
  Keep the small Tool Findy window open while using the app.

STOP
  Close the small Tool Findy window.

OFFLINE USE
  Sync is OFF by default. With sync disabled, Tool Findy makes no internet requests.
  Items, locations, history, settings, and daily snapshots stay in your browser's
  local database on this Windows computer.

SYNC
  Use the Allow web sync switch in Tool Findy to enable or disable all optional
  Google Sheets activity. Enabling the switch does not contact Google by itself;
  only Connect sheet or Sync now does. Turn the switch off again for device-only use.

CHAT-ASSISTED SORTING
  Put items in your existing "to be sorted" location, then open Sort inbox. Copy
  the generated prompt into any capable chat, copy its JSON response back, and load
  the suggestions for review. Tool Findy makes no AI API requests and needs no AI
  API key. Accepted moves become normal local changes that can sync to Google Sheets.

BACKUPS
  Use Backup inside Tool Findy to download a portable JSON copy of the inventory and
  full history. Use Restore to select that JSON file, review its record counts,
  and replace the local inventory after confirmation. Tool Findy saves a recovery
  snapshot immediately before each restore. Keep backups somewhere safe. Browser
  data is tied to the browser profile used to open http://127.0.0.1:4173.

INSTALLATION
  None. This folder includes its own runtime. It can be moved anywhere on the same
  Windows computer. Do not rename or remove the runtime or app folders inside it.
