FINDRY FOR WINDOWS - FULLY LOCAL
================================

START
  Double-click start-findry.cmd.
  Your normal browser opens Findry at http://127.0.0.1:4173.
  Keep the small Findry window open while using the app.

STOP
  Close the small Findry window.

OFFLINE USE
  Sync is OFF by default. With sync disabled, Findry makes no internet requests.
  Items, locations, history, settings, and daily snapshots stay in your browser's
  local database on this Windows computer.

SYNC
  Use the Allow web sync switch in Findry to enable or disable all optional
  Google Sheets activity. Enabling the switch does not contact Google by itself;
  only Connect sheet or Sync now does. Turn the switch off again for device-only use.

BACKUPS
  Use Backup inside Findry to download a portable JSON copy of the inventory and
  full history. Keep backups somewhere safe. Browser data is tied to the browser
  profile used to open http://127.0.0.1:4173.

INSTALLATION
  None. This folder includes its own runtime. It can be moved anywhere on the same
  Windows computer. Do not rename or remove the runtime or app folders inside it.
